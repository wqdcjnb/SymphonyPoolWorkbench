IMPORT ACCOUNTS

批量导入账号

直接上传登录资料文件，自动生成账号并分配节点。每个文件最多 100 个账号、5 MB。

Dola Cookie

文件内放一条或多条完整 Cookie，每个账号单独一行或一段。导入后自动恢复登录。

支持 TXT、Word（DOC / DOCX）、Excel（XLS / XLSX）和 CSV；无需账号编号或模板。

豆包手机号

文件内只需放手机号，每行或每个单元格一个。导入后在下方依次填写收到的验证码。

支持 TXT、Word（DOC / DOCX）、Excel（XLS / XLSX）和 CSV；无需账号编号或模板。
