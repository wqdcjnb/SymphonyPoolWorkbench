# 版本说明

## 1.3.0 · 2026-10-04

- Linux / Docker 的账号登录改用 Xpra 原生客户端，在 Windows 显示独立 Chrome 窗口；保留每个账号的浏览器档案。
- 登录页面以“直接打开 Xpra”为首位入口，另提供连接文件和结束登录窗口。重复打开复用本账号会话；失效连接不能进入其他账号。
- 修复关闭 Xpra 中的 Chrome 窗口后，在原登录页再次点击仍使用失效连接的问题；点击时重新取得可用连接，避免重复提交和静默失败。
- 登录浏览器使用自适应内容区域；通过正常关闭保存档案并释放调度占用。
- Xpra 网关仅监听回环地址，服务器部署经 SSH 隧道连接；更新 Docker、Ubuntu 部署和交付说明。
- Windows 中文用户名使用英文 Xpra 日志和缓存路径；原生 WebSocket 链接通过启动器传入设置，另提供桌面协议注册文件；启动失败显示明确提示。关闭启动进度窗、OpenGL 探测及登录用不到的音频等组件，指定 OpenH264 解码，保留键盘和双向剪贴板。
- 账号掉登录仍需根据平台返回定位；更换显示传输不承诺消除平台会话失效。

## 1.2.0 · 2026-09-30

- 自动队列排除被登录窗口或验收占用的浏览器档案；占用冲突只回到等待，不降低账号状态或清零额度，释放后默认 2 秒内重新选择账号。排队页面显示浏览器占用原因。
- 识别豆包提交时强制退出的情况，明确提示重新登录与核对任务，保留原任务防止重复生成。
- 修复 Chrome 提示已打开现有会话时，被只读验收误报为浏览器无法启动；豆包与 Symphony 统一识别档案占用。
- 修复不同账号打开后显示上一个账号浏览器的问题：Linux / Docker 每个账号分配独立登录桌面与专属连接，保留各自档案；重复打开复用本账号窗口，过期连接不会连接到其他账号。
- 修复粘贴时沿用远程旧剪贴板、读取权限受限时无法粘贴的问题：Ctrl+V 使用本次系统粘贴事件携带的文本，登录等单行输入直接传入；本机待粘贴内容与远程复制内容分开；剪贴板扩展加入版本缓存标识。
- 修复远程登录浏览器无法直接粘贴本机文本的问题，支持 Ctrl+V，并在剪贴板侧栏增加“粘贴到当前输入框”和“复制到本机”按钮。
- 修复远程浏览器小数字键盘无法输入的问题，消除客户端与虚拟桌面 Num Lock 状态不一致的影响。
- 修复 Docker 重启后的残留浏览器锁导致账号无法删除；删除和改编号时核对实际浏览器进程，并保护启动中的登录窗口。
- 本机 Docker 远程桌面改为免密连接，保留仅本机访问限制。
- 修复新增账号成功后页面误报失败、必须刷新才显示的问题；新增成功后直接更新账号列表。
- 账号卡片右上角加入删除图标及确认，删除账号和对应登录档案，保留历史任务与视频；有待处理任务时拒绝删除。
- 修复重复打开 Linux 登录窗口误报失败；识别并切回已有窗口，点击登录按钮时同步打开远程桌面标签页。
- 增加 Windows Docker Desktop 局域网测试部署，使用 Ubuntu 24.04 amd64、Chrome、虚拟桌面与 HTTPS 代理。
- 数据库、素材、视频、浏览器档案和证书分别持久化；测试密钥通过本机文件挂载，不写入镜像。
- 局域网只开放合作方 API 与静态接入文档；管理页和远程桌面仅映射到本机地址。
- 新增独立账号档案目录配置，以及公开代理请求经过 URL 规范化后的管理接口隔离检查。
- 提供 Windows 启动和端口放行脚本，生成包含测试 Key、根证书和请求示例的合作方接入文件夹。

## 1.1.0 · 2026-09-30

- 增加 Ubuntu 24.04 LTS 安装器，自动检测 x86_64 / ARM64，安装对应的 Node.js 与浏览器。
- Linux 自动使用 `.venv/bin/python`，提供持久化浏览器登录窗口；Windows 保留原登录启动方式。
- 统一显式配置的浏览器通道，使登录、验收和生成使用同一浏览器类型。
- 提供 Xvfb 虚拟桌面、noVNC 远程登录、systemd 用户服务和 HTTPS API 代理配置示例。
- 远程管理默认通过 SSH 隧道访问，API 服务继续监听本机地址。
- 交付包包含 Linux 脚本及部署说明，保留正确的脚本换行和执行权限，继续排除全部私有运行数据。
- 修复上游队列在轮询先后收到完成状态时提前拆批的问题：两条一轮的请求等待完整名额，最后不足两条时按剩余数执行。

服务器平台的真实登录、账号验收、生成和公网交付需在实际部署环境完成；ARM64 的 Chromium 媒体兼容性需另行实测。

## 1.0.0 · 2026-09-30

第一版交付基线：

- 账号池：独立浏览器档案、手动登录、只读验收、模型及额度记录。
- 视频生成：纯文字或参考图片、独立正反提示词、三种模型及参数校验。
- 调度：近期验收快速筛选、额度优先、单账号互斥、安全换号和提交不明时核对。
- 工作台：账号、任务、审计事件和 API 文档四个入口；根地址默认进入任务页。
- 合作方 API：共享 Bearer Key、双方任务 ID、防重、随任务上传图片、每批最多两条、查询和取消。
- 结果交付：原始 MP4 签名下载、Range 请求、SHA-256 校验、持久化回调及通知重试。
- 干净发布：源码白名单打包、依赖版本固定、文件校验清单；账号、任务、视频及本机配置排除在交付包外。

### 部署时配置

- 公网 HTTPS 域名、API Key、下载签名密钥。
- 可选的回调地址白名单、默认回调地址及回调签名密钥。
- 本机浏览器账号登录与验收。

### 当前限制

- 依赖 Windows、本机 Chrome / Edge 以及平台网页自动化；平台改版可能需要调整执行器。
- 豆包额度为估算值，明确的额度耗尽提示优先。
- TikTok 使用平台默认竖屏输出；负面提示词以排除要求附加到平台提示词。
- 单元与集成测试使用模拟执行器；自动测试不消耗真实平台额度。
