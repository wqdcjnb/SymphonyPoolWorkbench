# 版本说明

## 1.1.0 · 2026-09-30

- 增加 Ubuntu 24.04 LTS 安装器，自动检测 x86_64 / ARM64，安装对应的 Node.js 与浏览器。
- Linux 自动使用 `.venv/bin/python`，提供持久化浏览器登录窗口；Windows 保留原登录启动方式。
- 统一显式配置的浏览器通道，使登录、验收和生成使用同一浏览器类型。
- 提供 Xvfb 虚拟桌面、noVNC 远程登录、systemd 用户服务和 HTTPS API 代理配置示例。
- 远程管理默认通过 SSH 隧道访问，API 服务继续监听本机地址。
- 交付包包含 Linux 脚本及部署说明，保留正确的脚本换行和执行权限，继续排除全部私有运行数据。
- 修复上游队列在轮询先后收到完成状态时提前拆批的问题：两条一轮的请求等待完整名额，最后不足两条时按剩余数执行。

服务器平台的真实登录、账号验收、生成和公网交付需在实际部署环境完成；ARM64 的 Chromium 媒体兼容性需另行实测。

## 1.0.0 · 2026-09-30

第一版交付基线：

- 账号池：独立浏览器档案、手动登录、只读验收、模型及额度记录。
- 视频生成：纯文字或参考图片、独立正反提示词、三种模型及参数校验。
- 调度：近期验收快速筛选、额度优先、单账号互斥、安全换号和提交不明时核对。
- 工作台：账号、任务、审计事件和 API 文档四个入口；根地址默认进入任务页。
- 合作方 API：共享 Bearer Key、双方任务 ID、防重、随任务上传图片、每批最多两条、查询和取消。
- 结果交付：原始 MP4 签名下载、Range 请求、SHA-256 校验、持久化回调及通知重试。
- 干净发布：源码白名单打包、依赖版本固定、文件校验清单；账号、任务、视频及本机配置排除在交付包外。

### 部署时配置

- 公网 HTTPS 域名、API Key、下载签名密钥。
- 可选的回调地址白名单、默认回调地址及回调签名密钥。
- 本机浏览器账号登录与验收。

### 当前限制

- 依赖 Windows、本机 Chrome / Edge 以及平台网页自动化；平台改版可能需要调整执行器。
- 豆包额度为估算值，明确的额度耗尽提示优先。
- TikTok 使用平台默认竖屏输出；负面提示词以排除要求附加到平台提示词。
- 单元与集成测试使用模拟执行器；自动测试不消耗真实平台额度。
